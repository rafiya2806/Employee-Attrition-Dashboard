# Employee Attrition Dashboard – Power BI

## Project Overview
This project analyses employee attrition using Microsoft Power BI. It helps understand employee turnover and identify important HR trends.

## Tools & Technologies
- Microsoft Power BI
- Power Query
- DAX
- Data Modelling
- Data Visualization

## Key Insights
- Employee count by department and gender
- Employee attrition analysis
- Monthly income by job role
- Employee performance by gender
- Job satisfaction analysis
- Age group and salary analysis

## Skills Demonstrated
- Data Cleaning
- Data Analysis
- Dashboard Development
- Data Visualization
- Business Insights
